## ✨ Features

- 🔗 Paste any YouTube video link
- 📷 Instantly fetch the thumbnail image
- 🖼️ Preview before downloading
- 📥 Download in:
  - Medium Quality
  - Normal/Standard Quality
  - High Definition (HD)

---

## 🚀 Live Demo

Check out the tool in action: [YT_Thumbnail-Grabber](https://yt-thumbnail-grabber.netlify.app/)

---

## 🧠 How It Works

1. User pastes a valid YouTube video URL.
2. The tool extracts the video ID and constructs direct thumbnail image URLs.
3. Thumbnails are displayed with options to **preview** or **download**.
